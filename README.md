### ✅ 求职者端功能

- 首页：城市定位、职位搜索，四大分类入口：全部职位、急招岗位、兼职招聘、红包招聘；搭配招聘公告、名企推荐。
- 找工作：多维度筛选（区域、行业、薪资），岗位卡片展示薪资、地点、学历、工作年限、福利标签（五险一金、双休、补贴）。
- 个人中心：岗位推荐、待评价、消息中心；面试邀请、申请记录、我的收藏；简历在线编辑；我看过谁、谁看过我、评论、隐私设置。
- 简历详情：展示基础信息、意向岗位、联系方式、个人标签，企业端可直接查看。

### ✅ 企业端功能（一键切换身份）

- 发布管理、消息中心；人才推荐、应聘简历、面试邀请统一管理。
- 企业主页：完善企业信息、上传公司简介、环境图，提升曝光。
- 找人才：浏览简历库，筛选合适候选人，发起面试邀约。
- 面试邀约管理：面试待同意、拒绝、面试中、录用、不合适状态分类，可填写面试时间、地址、联系人、备注。

### ✅ 核心业务流程

企业发布岗位 → 用户浏览搜索岗位 → 投递简历 → 企业查看简历 → 发送面试邀请 → 求职者确认面试 → 面试结果标记（录用 / 不合适），闭环完整。
